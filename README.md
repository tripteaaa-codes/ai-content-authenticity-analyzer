# AI Content Authenticity Analyzer

An AI-powered platform that analyzes digital content
(text, images, videos, audio) to estimate whether it
is human-created, AI-generated, or manipulated.

## Planned Features

- Text authenticity detection
- AI image detection
- Video deepfake analysis
- Audio authenticity checking
- Digital forensic reports

## Tech Stack

- Node.js
- Express
- MongoDB
- React
- AI/ML models (future)
